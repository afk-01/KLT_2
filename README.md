# Visualización de Presupuesto Municipal

Muestra de forma visual el análisis del presupuesto municipal.

## ¿Qué hace?

- Muestra el presupuesto total, gasto total y balance general
- Presenta una tabla con el detalle de cada categoría
- Resalta en rojo las categorías en riesgo (más del 85% de ejecución)
- Destaca la categoría con mayor gasto
- Diseño oscuro y responsive
